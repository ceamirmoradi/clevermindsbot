# Clever Minds Mafia — نسخه 0.4

این نسخه شامل موارد زیر است:

- ساخت بازی با کد چهاررقمی
- سناریوهای بازپرس، مذاکره و عقرب
- ثبت درخواست ورود بازیکن
- تأیید یا رد بازیکن توسط گرداننده
- تأیید بازیکن بدون وابستگی به ترتیب ثبت‌نام
- قرعه‌کشی تصادفی صندلی‌ها پس از بسته‌شدن ثبت‌نام
- امکان قرعه‌کشی مجدد صندلی‌ها فقط پیش از شروع بازی
- یک پنل زنده برای گرداننده
- انتقال گردانندگی به بازیکن تأییدشده
- شروع بازی فقط با ۱۰ بازیکن تأییدشده
- ساختار ماژولار و قابل توسعه

## تنظیمات Render

Environment Variables:

- `BOT_TOKEN`
- `WEBHOOK_URL=https://clevermindsbot.onrender.com`
- `PYTHON_VERSION=3.11.9`

Build Command:

```bash
pip install -r requirements.txt
```

Start Command:

```bash
python bot.py
```

## نکته مهم

اطلاعات فعلاً داخل حافظه موقت ذخیره می‌شوند؛ بنابراین با ری‌استارت Render بازی‌ها پاک می‌شوند.
مرحله بعد اتصال PostgreSQL است.


## نسخه 0.5 — سناریوی داده‌محور و تقسیم نقش

- سناریوی عقرب با ۱۰ نقش کامل اضافه شد.
- نقش‌ها هنگام شروع بازی به‌صورت تصادفی تقسیم می‌شوند.
- نام، ساید، شماره صندلی و توضیح نقش به‌صورت خصوصی برای هر بازیکن ارسال می‌شود.
- فهرست کامل و محرمانه نقش‌ها فقط برای گرداننده نمایش داده می‌شود.
- سناریوهای بازپرس و مذاکره تا زمان اضافه‌شدن نقش‌ها قابل شروع نیستند.
- فولدرهای `__pycache__` داخل فایل ZIP قرار نگرفته‌اند.

نکته: هر بازیکن باید پیش از شروع بازی حداقل یک بار بات را با `/start` فعال کرده باشد تا تلگرام اجازه ارسال پیام خصوصی نقش را بدهد.


## نسخه 0.6 — اخراج بازیکن و Event Log

- گرداننده می‌تواند فقط در فاز روز، بازیکن فعال را اخراج کند.
- دلیل اخراج از میان گزینه‌های مشخص انتخاب می‌شود.
- بازیکن اخراج‌شده فوراً `alive=False` و `can_act=False` می‌شود.
- اکشن‌های ثبت‌شده قبلی او از صف اکشن‌ها حذف و باطل می‌شوند.
- بازیکن اخراج‌شده در شب بعد هیچ دکمه یا اکشنی دریافت نمی‌کند.
- وضعیت، دلیل، نقش، ساید، فاز و گرداننده اخراج‌کننده در Event Log ثبت می‌شوند.
- دکمه‌های تغییر فاز روز/شب و مشاهده تاریخچه بازی اضافه شدند.
- اخراج اداری هیچ قابلیت ویژه «هنگام مرگ یا خروج» را فعال نمی‌کند.
